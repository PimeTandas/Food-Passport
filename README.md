# Food-Passport
This app has been vibe coded from my phone on the train.

Collect a "stamp" for every dish you try from around the world.

## Backend (Spring Boot)

Requires Java 21 and Maven.

```bash
cd backend
mvn spring-boot:run   # starts on http://localhost:8080
mvn test              # runs the tests
```

### How the code is layered

```
HTTP request
   │
   ▼
StampController   (web layer: URLs ⇄ JSON)
   │
   ▼
StampService      (business rules)
   │
   ▼
StampRepository   (data access, generated by Spring Data)
   │
   ▼
H2 database       (in-memory, resets on restart)
```

### API

| Method | URL                         | What it does                       |
|--------|-----------------------------|------------------------------------|
| GET    | `/api/stamps`               | List stamps (`?country=Japan` to filter) |
| GET    | `/api/stamps/{id}`          | Get one stamp                      |
| POST   | `/api/stamps`               | Add a stamp                        |
| PUT    | `/api/stamps/{id}`          | Update a stamp                     |
| DELETE | `/api/stamps/{id}`          | Remove a stamp                     |
| GET    | `/api/passport`             | Summary: totals and stamps per country |

Example:

```bash
curl -X POST localhost:8080/api/stamps -H 'Content-Type: application/json' \
  -d '{"dishName":"Ramen","country":"Japan","rating":5,"notes":"Rich tonkotsu broth"}'
curl localhost:8080/api/passport
```
